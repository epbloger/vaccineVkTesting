## 📌 Название бага

> **Возможность фармить вакцину, имея два устройства, благодаря пассивному заработку**

Пользователь может неограниченно получать внутриигровую валюту («вакцину»), поочерёдно запуская мини-приложение на двух устройствах и пользуясь механизмом пассивного дохода. Это позволяет обходить правила приложения и получать ресурсы в обход задуманного геймплея.

## 🔁 Шаги воспроизведения

1. Возьмите **два устройства** — например, телефон и ноутбук.
2. Запустите приложение на телефоне и дождитесь появления плашки:
   > «Пока вас не было, мы заработали вакцины…»
3. Сразу же запустите приложение на компьютере.
4. На телефоне приложение покажет ошибку **«Все сломалось»** — нажмите **«Попробовать снова»** и дождитесь загрузки.
5. Повторите те же действия на компьютере.
6. Повторяйте шаги 2–5 циклично.

---

## ❌ Фактический результат

При выполнении описанных действий приложение **поочерёдно** запускается на устройствах, и на баланс пользователя **постоянно начисляется вакцина** за счёт пассивного заработка. Каждый цикл перезапуска приносит новую порцию ресурсов.

**Последствия:**
- Нарушение игровой экономики мини-приложения.
- Возможность неограниченного получения внутренних ресурсов.
- Обход правил приложения без использования стороннего ПО.

---

## ✅ Ожидаемый результат

При выполнении описанных действий приложение должно показать уведомление о пассивном заработке **только один раз**. При последующих перезапусках:

- уведомление **не появляется**;
- вакцина **не начисляется**.

Пассивный доход должен быть привязан к реальному времени отсутствия пользователя, а не к факту перезапуска приложения.

## 🧠 Анализ проблемы

| Аспект | Описание |
|---|---|
| **Корень проблемы** | Серверная логика пассивного заработка не учитывает одновременные/поочерёдные сессии с разных устройств. |
| **Триггер** | Перезапуск приложения после появления плашки пассивного дохода. |
| **Влияние** | Экономический дисбаланс, обесценивание внутриигровой валюты, потеря доверия пользователей. |
| **Критичность** | Высокая — эксплуатируется без специальных знаний. |
